# Детекция скраперов по cookie_id

Бинарная классификация: по логам событий за суточное окно определить, стоит ли за `cookie_id`
автоматический сборщик данных. Метрика: precision при recall не ниже 0.70.

**Результат на тесте: 0.88329.** Константный ответ там даёт 0.09391.

Собственная оценка по out-of-fold предсказаниям была 0.8736, то есть тест оказался выше на 0.0097
при измеренном шуме метрики 0.041. Расхождение объясняется составом теста: константа на нём даёт
0.09391 против 0.081 на train, то есть ботов там относительно на 16% больше, а чем их больше, тем
легче держать precision при той же полноте. С поправкой на это модель отработала ровно так, как
показывала кросс-валидация.

Всё решение целиком лежит в одном ноутбуке [`solution_final.ipynb`](solution_final.ipynb):
десять ячеек, прогон около минуты. Ноутбук самодостаточен, метрика организаторов скопирована
внутрь, внешних модулей проекта не требуется. На выходе `submission.csv`.

| что | где |
|---|---|
| решение | `solution_final.ipynb` |
| данные | `data/` |
| ответ | `submission.csv` |
| официальная метрика | `metric.py` |
| всё остальное | `theories/` |

В `theories` лежит ход работы: черновые ноутбуки, разбор данных, проверка протоколов валидации,
перебор гиперпараметров, разбор непойманных ботов и справочник всех признаков с таблицей
отклонённых идей ([`theories/FEATURES.md`](theories/FEATURES.md)). Проверено двадцать четыре
идеи, принято две. Для запуска решения эта папка не нужна.

## Как запустить

Python 3.10.6. Из корня проекта:

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m ipykernel install --user --name ml-avito --display-name "Python 3.10 (ML Avito)"
```

В PowerShell те же три строки пишутся через `&`, например
`& .\.venv\Scripts\pip.exe install -r requirements.txt`.

Дальше запустить Jupyter и открыть ноутбук:

```bash
.venv/Scripts/jupyter-lab
```

Ядро выбрать `Python 3.10 (ML Avito)` и выполнить ячейки сверху вниз.

Без Jupyter, прямо в консоли:

```bash
.venv/Scripts/python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=ml-avito solution_final.ipynb
```

## Воспроизводимость

`random_state=42` зафиксирован везде, где есть случайность. `requirements.txt` это полный
слепок окружения, в котором получен результат. Ключевое: xgboost 3.2.0, scikit-learn 1.7.2,
pandas 2.2.3, numpy 1.26.4. Обучение на CPU: на этих данных GPU не быстрее, а числа даёт другие
из-за иной реализации гистограмм.

Повторный прогон даёт побайтово тот же `submission.csv`.

## Ограничения

Языковые модели и внешние API не используются. Решение работает только с предоставленными
данными и перечисленными в `requirements.txt` библиотеками, доступ в интернет не требуется.
Ручной разметки тестовых данных и подгонки под конкретные `cookie_id` нет.
